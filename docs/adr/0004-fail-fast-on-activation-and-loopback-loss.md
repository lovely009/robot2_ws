# 历史：激活失败与回环终止

**Status:** superseded in part（2026-08-25）

早期方案围绕硬件插件激活和本地回环定义 fail-fast。相关进程已经删除，但“通信失效
立即停止输出”的安全原则继续保留在当前单包仿真中：

- 任一路串口断开，立即发布 30 个零 effort，并关闭整个仿真 launch；
- 命令超过 150 ms、越限、来自错误总线或检测到重复控制器时，锁存全机零输出；
- 电机在收到显式 enable 前不产生驱动力；
- 普通后续命令不能自动清除锁存故障，必须诊断后重启。

这些措施只约束 Gazebo 仿真，不构成真实机器人的功能安全设计。
