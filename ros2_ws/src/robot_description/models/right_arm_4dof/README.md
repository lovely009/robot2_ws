# 右臂四自由度机械模型

`right_arm_4dof` 保留 9 个连杆、4 个转动关节和 4 个固定关节，关节名为 `Joint_link1` 至 `Joint_link4`。`urdf/` 提供机械模型及相同的 standalone，`meshes/` 保存原始 9 个 STL。

`cad/` 保留机械来源和零点标定工具；现存来源摘要见 `source_sha256.json`。原始 MJCF 与使用 MuJoCo 计算补偿的 SocketCAN 真机脚本保留为来源资料；公共仿真模型和 Gazebo 启动入口已移除。这些脚本会操作真实电机，必须获得专项授权后使用。运行 URDF 沿用此前选定的关节轴、惯量、阻尼、摩擦、力矩和角度范围。

速度上限保留来源值 0；力矩为 10 / 5 / 5 / 5 N·m。部分质量属性含网格估算值，未独立标定；使用实机控制前仍须核验映射、方向、零位和限位。零点标定工具操作真实 CAN 电机，必须获得专项授权后使用。

`source_sha256.json` 记录本次裁剪后现存来源文件的摘要；`zero.py` 已去除 Viewer 分支，保留标零、只读检查和自测。
