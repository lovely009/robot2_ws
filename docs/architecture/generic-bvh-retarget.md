# 通用 BVH 离线转换

输入为 BVH 和 URDF。解析格式并不能唯一推断机器人关节的人体语义，因此首次识别给出候选和疑点；用户确认后保存映射，同一组合再次导入自动转换。所有结果保持 `preview_only`，不连接电机或修改模型参数。

## 范围

- 复用 BVH 解析、Pinocchio、SciPy 和现有动作任务、进度、下载、Three.js 预览。
- 树形 URDF 的 fixed、revolute、continuous、prismatic；mimic 按比例/偏移从属，检测循环、缺失引用和不相容限位。
- 浮动/平面多自由度关节及闭环不猜测为独立单轴；报告具体不支持项。
- 名称与人体语义产生候选，重复/无语义名称标为待确认；拓扑决定目标能影响哪些关节。未覆盖分支保持参考位。
- 支持任意数量的目标对应，不限定双臂；人体根参考、机器人坐标、参考帧可确认。
- 第一参考帧对应机器人参考位，拟合相对旋转；移动关节拟合相对平移。固定基座不输出人体根位移，不承诺足底接触、平衡或自碰撞安全。

## 实现

`bvh_broadcaster.generic_retarget` 集中模型适配、候选分析、映射校验和求解。用实际运动学雅可比拟合目标，保留上一帧初值及连续性项。URDF 原始数值不改写。

正常模式约束有效位置和速度限位。CAD 零范围/缺速度会列出诊断，用户可明确选择“仅几何预览”；此模式只跳过缺失的约束，并在导出及预览中持续标记。它不建立可执行的硬件轨迹。

`MotionJobs` 增加 `retargeting: generic` 输入，旧客户端双臂/肩转换保留。通用任务使用现有状态 `mapping/running/done/failed`，附带候选、诊断、覆盖范围及映射来源。先验证映射再启动计算；不在持有任务锁期间执行完整转换。

确认后的映射保存到用户数据目录；键包含版本、完整 URDF 摘要、BVH 层级/通道/偏移、参考姿势、坐标和单位。每次读取重新验证，失效/损坏回到确认；原子替换单个记录，测试使用临时目录，不读取或覆盖正式缓存。

网页复用当前导入、进度与结果视图，增加通用对应表、疑点与限位策略；可选择不对某个连杆设置目标。映射可重新编辑，导出报告说明覆盖与误差。几何预览允许显示超出原 CAD 零限位的姿态，但不改变原 URDF，也不影响控制页的限位。

## 验收

1. 新的不同名称/数量/结构的 URDF 可分析、人工确认并转换，不依赖项目模型名。
2. 连续关节跨角度边界、移动关节和 mimic 正负比例得到正确有限结果；畸形映射拒绝。
3. CAD 零限位要求明确选择几何预览，原 URDF 哈希不变；输出持续标记预览及未约束项。
4. 同一骨架/模型/参考姿势确认一次后复用；模型、骨架或参考姿势改变后重新确认。
5. 保留已有双臂/肩转换回归；实际全身短片、预览资源与浏览器确认流程通过。
6. 独立审查接口、映射缓存、限位和数值约束；部署只更新转换/网页安装件，不重启控制栈或操作电机。
