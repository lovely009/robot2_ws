# 工程文档

本目录保存跨工作区、ROS 2 主机侧和工程治理资料。**固件架构、固件台架、板卡及电机协议参考资料统一进入
[`micro_ros_firmware/docs`](../micro_ros_firmware/docs/README.md)**，不在两处重复维护。

## 分类规则

- `adr/`：影响多个包或工作区的架构决策。正文保留作出决策时的上下文；顶部与索引说明当前适用性。
- `research/`：仍有参考价值、但不直接定义当前实现的调研资料。
- `reports/`：跨工程的事实记录；报告不代替当前 README 或 ADR。
- `guides/`：当前可重复执行的操作流程；一次运行的数据与判断归入 `reports/`。
- `micro_ros_firmware/docs/`：固件开发资料（ARD/ADR/设计基线/交接/开放验收）与
  厂商参考资料，扁平结构；台架报告与活动计划在本目录 `reports/`。
- `ros2_ws/src/<package>/README.md`：包的运行入口、接口、配置和维护边界；包级 API/协议说明就近保存。

## 文档状态

文档顶部或索引使用以下状态：

- **当前**：描述当前工作区，可作为开发入口；
- **提议**：方向已形成，但仍缺实现或验证证据；
- **历史/部分被取代**：保留原始事实，当前开发必须继续查看替代文档；
- **活动计划**：尚有未完成验收项，完成后记录最终结果并转入 reports。

实体迁移时优先使用 `git mv`，并同步修复入口、相对链接和命令路径。历史报告只补状态与后续链接，不把当时观察改写为后来结论。
