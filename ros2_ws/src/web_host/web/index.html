    电机参数

    设零：把该台当前姿态设为设备零点（写 0x2531=1）。厂家要求 失能状态下设置——运行中会被固件拒绝，不会隐式失能；零点改变后设备内的 位置限位随之移动，请重新确认限位与机械行程。 单位：位置 度、速度 度/秒、力矩 安培（设备里的对象就是 cnt / RPM / mA，rad 与 N·m 只在固件内核里用；换算由固件在参数边界做一次）。 参数在固件内核生效：kp/kd/enable 本地立即生效；pos/vel/torque 限值 VAXOR 为 MCU 本地软钳制，CERB 走 CANopen SDO 写后读回核验（要求电机未运动， 运行中写入会被拒绝并回弹）。set 仅表示「已受理」，最终成败看事件日志的 CONFIG_RESULT（失败自动回弹旧值）。「回读」对 CERB 逐条发 SDO upload （设备是严格一问一答，4 个对象读完约 1 秒）刷新设备真实值。「保存到 W25」显式落盘，掉电恢复（enable 不持久化）。 参数以驱动板内为准：「来源」列标出这行数字取自驱动板（在线）还是固件记录 （离线回落）；上电时固件会逐台回读并与 Flash 记录比对，初始化未完成（未回读完 / 与记录不一致 / 回读失败）的那台不可使能（状态列显示 CONFIG_CONFLICT）， 从本页写回参数即可恢复一致。运行中回读发现不一致会走软停（阻尼停机），不硬失能。
