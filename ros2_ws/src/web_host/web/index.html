    电机参数

    设备参数核对：连接后点「读取」

    单位：位置 度、速度 度/秒、力矩 安培（换算由固件在参数边界做）。 限值与保护开关仅在电机未运动时受理；设零要求失能。 限位保护取消勾选 = 关闭设备侧看门狗与限位保护，该关节将 没有任何限位在执行（急停与机械限位仍需就位）；该设置掉电不保存， 每次上电需重新开启。 设备侧写成功后自动落盘，「保存到 W25」用于本地参数的显式落盘。

    逐电机策略 /motor_policy

    稀疏：只影响下发的电机，其余保持原状（与命令快照的「缺席即软停」不同）。 代数必须严格前进才受理「未武装 → 武装」，防止周期重发在故障后自动复权。
