# RP 系列行星关节

意优 RP 一体化行星关节（内置驱动器，CAN-FD MIT 模式）。对应 `motor_drive`
内置 `rp` 协议。

来源：`【外部】全新RP系列规格表V2.2 20260710.pdf`、
`意优RP系列行星关节CAN-FD通信协议.pdf`。

本文档已覆盖上述两份资料的可操作信息（规格/机械承载/寄存器/控制帧/故障），
无需再翻 PDF。

## 通信接口

| 项 | 值 |
|---|---|
| 接口类型 | CAN FD |
| 位率 | 仲裁 1 Mbps + 数据 5 Mbps |
| 采样点 | 协议文档标注 75%；Pn2 寄存器默认仲裁 80%、数据 75%（可配，见下） |
| 帧格式 | 标准帧 / 扩展帧 29 bit，禁用远程帧 |
| 通信 | 一问一答，应答超时 50 ms，发送 ID == 应答 ID |
| 单总线 | 最多 8 台（64 B 广播帧 8 槽位限制） |
| 默认配置 | 关节正向 = 正视输出轴逆时针；默认运动范围 ±π |

## 寄存器通信（扩展帧 29 bit ID）

| 位域 | 含义 |
|---|---|
| Bit0–6 | 设备 ID（默认 0x01，范围 0x01–0x08） |
| Bit7 | 保留 |
| Bit8–14 | 产品 ID（默认 0x01） |
| Bit15 | 读写成功标志（0=成功，1=异常） |
| Bit16–23 | 寄存器地址 |
| Bit24–27 | 子寄存器地址 |
| Bit28 | 读写标志（0=读，1=写） |

多字节小端、float 按 IEEE-754；写寄存器须匹配长度，读无限制；配置写后掉电
保存、重启生效。

### 寄存器地图

| 地址 | 名称 | 关键子地址 |
|---|---|---|
| 0x01 | Pn1 厂家信息 | 型号 / 序列号 / 硬软件版本 |
| 0x02 | Pn2 设备信息 | ID 寄存器、通信参数配置（见下） |
| 0x03 | Pn3 MIT 阈值 | 位置/速度/扭矩/Kp/Kd 上下限 |
| 0x04 | Pn4 Level1 保护 | MOS 过温 / 过流 / 过压 告警与恢复阈值 |
| 0x05 | Pn5 Level2 保护 | 同上，触发后主动停机 |
| 0x06 | Pn6 位置模式 | 梯形加速 / 匀速 / 减速、位置增益 P |
| 0x07 | Pn7 速度模式 | 速度增益 P、积分 I |
| 0xA0 | Pn08 功能设置 | 模式配置、零位设置、故障寄存器 |
| 0xB0 | 其他 | 速度滤波截止频率、电流限制、输出力矩限制 |

### 常用操作

- **设当前为零位**：写 Pn08 子 0x02 = `0x01`，应答 `0x01` 表示成功。
- **读 / 清故障**：读 Pn08 子 0x03 得故障位；写 `0x0000` 清除所有错误。
- **切 PP / PV 模式**：先停机，再写 Pn08 子 0x01。

### 通信参数配置（Pn2 子地址 0x02，4 B，重启生效）

| 字节 | 字段 | 默认 | 取值 |
|---|---|---|---|
| 0 | 仲裁波特率 | `0x02` = 1 M | 0=125K · 1=500K · 2=1M |
| 1 | 仲裁采样点 | `0x01` = 80% | 0=75% · 1=80% · 2=87.5% |
| 2 | 数据波特率 | `0x03` = 5 M | 0=125K · 1=500K · 2=1M · 3=5M |
| 3 | 数据采样点 | `0x00` = 75% | 0=75% · 1=80% · 2=87.5% |

协议文档前端标注采样点 75%，Pn2 寄存器默认仲裁 80% / 数据 75%，以寄存器为准。
与 25/30 mm（采样点 80%）混挂同一总线时，把数据域采样点配为 80%。

### MIT 阈值（Pn3）

位置 ±10 rad、速度 ±60 rad/s、扭矩 ±60 N·m、Kp 0~500、Kd 0~10。

## 控制帧（标准帧）

所有控制帧均为**标准帧 ID**（11 bit）；数据域超过 8 字节的帧（64 B 广播、12 B
应答）必须使用 CAN FD 数据域。

| 帧 | CAN ID | 类型 | 长度 | 默认 N=1 |
|---|---|---|---|---|
| 使能 / 失能 | `0x00` | 标准帧 · classic | 8 B（Byte0 = `0x01`/`0x00`，Byte1–7 预留） | `0x00` |
| MIT 广播 | `0x80` | 标准帧 · FD | 64 B = 8 槽 × 8 B | `0x80` |
| 经典单节点（PP/PV） | `0x80 + N` | 标准帧 · classic | 4 B（Float） | `0x81` |
| 应答 | 设备 ID 1–8 | 标准帧 · FD | 12 B | `0x01` |

- **使能帧**（`0x00`）：Byte0 `0x01` 使能 / `0x00` 失能，Byte1–7 预留。
- **PP 规划位置模式**（`0x80+N`，N=1 → `0x81`）：Byte0–3 = 期望位置 Float。
- **PV 规划速度模式**（`0x80+N`，N=1 → `0x81`）：Byte0–3 = 期望速度 Float。

### MIT 命令槽位 · 8 B/关节 · `0x80` 广播

一帧 64 B 携带 8 个关节槽位，设备 ID 1 → 槽位 0（Byte0–7）、设备 ID 8 → 槽位 7
（Byte56–63）。每槽 8 B，12 bit 字段跨字节拼接：

| 字段 | 字节位域 | 位宽 | 范围 |
|---|---|---|---|
| 位置 | Byte0–1 | 16 | −10 ~ 10 rad（0x7FFF = 0） |
| 速度 | Byte2 + Byte3 高 4 位 | 12 | −60 ~ 60 rad/s（0x7FF = 0） |
| Kp | Byte3 低 4 位 + Byte4 | 12 | 0 ~ 500（0x000 = 0） |
| Kd | Byte5 + Byte6 高 4 位 | 12 | 0 ~ 10（0x000 = 0） |
| 扭矩（前馈） | Byte6 低 4 位 + Byte7 | 12 | −60 ~ 60 N·m（0x7FF = 0） |

编码为线性映射 `code = (x − xmin) × (2^bits − 1) / (xmax − xmin)`。

下行解析（主站从 8 B 槽位还原物理量）：

```c
pos_tmp = (d[0] << 8) | d[1];
vel_tmp = (d[2] << 4) | (d[3] >> 4);
kp_tmp  = ((d[3] & 0x0F) << 8) | d[4];
kd_tmp  = (d[5] << 4) | (d[6] >> 4);
tor_tmp = ((d[6] & 0x0F) << 8) | d[7];
```

全中性槽位（0 位置/速度/扭矩、0 Kp/Kd）= `7F FF 7F F0 00 00 07 FF`，
8 槽全为 `7FFF7FF0000007FF`。

### MIT 应答 · 12 B · 设备 ID 1–8（默认 `0x01`）

| 字节 | 字段 | 位域 / 换算 |
|---|---|---|
| 0–1 | 位置（16 bit） | 0x0000~0xFFFF → −10 ~ 10 rad，0x7FFF = 0 |
| 2–3 | 速度（12 bit） | Byte2 + Byte3 高 4 位；0x000~0xFFF → −60 ~ 60 rad/s，0x7FF = 0 |
| 3–4 | 扭矩（12 bit） | Byte3 低 4 位 + Byte4；0x000~0xFFF → −60 ~ 60 N·m，0x7FF = 0 |
| 5 | MOS 温度 | uint8，编码 = 温度 + 40（−40 ~ 215 ℃） |
| 6–7 | 电机状态 | 16 bit，见故障寄存器位定义 |
| 8 | 电压 | uint8，0 ~ 255 → 0 ~ 255 V |
| 9 | 线圈温度 | uint8，编码 = 温度 + 40（−40 ~ 215 ℃） |
| 10–11 | 预留 | — |

上行拼接：`d[2] = 速度 >> 4`、`d[3] = (速度低 4 位 << 4) | (扭矩 >> 8)`、
`d[4] = 扭矩`；`d[5]` MOS 温度、`d[6:7]` 状态、`d[8]` 电压、`d[9]` 线圈温度。

### 故障寄存器（16 bit）

bit0 使能状态 · bit1/2 1/2 级过压 · bit3/4 1/2 级过流 · bit5/6 MOS 1/2 级过温 ·
bit7 超速 · bit8 过载 · bit9 超差 · bit10 堵转 · bit11 预驱故障 · bit12 编码器 ·
bit13 欠压 · bit14/15 线圈 1/2 级过温。

Level1 告警：不干涉运行、自动恢复，标志位手动清除；Level2 故障：主动停机、
手动清除；bit6 及之后同 Level2，不可自动恢复。清除方式：对应位写 0 或整个
寄存器写 0。

## 参数

- 反馈位置/速度/扭矩均为实际关节侧量（内置驱动已折算），无需 Kt、
  无需 `gear_ratio` 换算。
- 关节默认运动范围 ±π；正转方向为正视输出轴逆时针。
