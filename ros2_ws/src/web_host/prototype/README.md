# Web 工作台交互原型

临时 UI 原型，用来比较三种工作布局和三个工作场景。代码保留在 Web 功能分支供评审，
布局确认后按正式模块和测试边界重新实现；不将实验切换器整体合入开发分支。

模型几何、关节和设备映射来自 `robot_sim/models/` 的 URDF/YAML。位置曲线、会话状态、
下发回执和执行进度都是本地模拟。没有 ROS 连接，不访问串口，不启动仿真进程。
无设备映射的模型只提供几何与动作预览，不回退到其他模型的设备表。

## 启动

需要 Node.js 22.12+（已使用 24.19 验证）、Python 3 与已有 PyYAML。

```bash
cd ros2_ws/src/web_host/prototype
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/?variant=A#/run>。旧版上位机仍用现有 ROS launch，二者独立。

| 参数         | 布局                                         |
| ------------ | -------------------------------------------- |
| `?variant=A` | 均衡工作台：对象树、主工作区、检查器、观察区 |
| `?variant=B` | 3D 优先：大视图、浮动检查器、底部对象列表    |
| `?variant=C` | 表格优先：设备表为主，几何作为参考窗         |

页面底部按钮或左右方向键切换布局；编辑输入时方向键保持原行为。
`#/run`、`#/teach`、`#/sim` 切换场景，保留选择、目标草稿、关键帧和事件。
所有状态仅保存在当前页面内存中，刷新重置；布局参数与场景保留在 URL。

可体验：对象树/表格/3D 点选联动、目标草稿与姿态叠影、动作记帧和时间轴预览、
模拟动作执行/停止、模拟断连及控制禁用、停止会话后更换配置、日志导出。
动作预览只移动叠影，不改变独立生成的实测样本。

## 验证与范围

```bash
npm run check
npm run build
```

`build` 检查类型和资源打包；只读模型 API 与源码几何挂载目前由 Vite 开发服务提供，
`dist/` 不是可替换正式上位机的独立部署件。正式构建安装需要另行设计并更新 ADR 0010。
原型没有参数写入/保存、动作文件导入导出、真实数据录制或运动规划能力。
首次载入模型需读取仓库 STL，后续模型切换仍可能需要等待几何加载。
