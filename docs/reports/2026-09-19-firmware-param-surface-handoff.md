## 一、这次会话的结论（已落盘、可信）

### 1. `0x2650` 对象语义（owner 手工核实 + SLCAN 复现）

| 操作 | 帧 |
|---|---|
| 读 | `40 50 26 00 00 00 00 00` → `43 50 26 00 0x 00 00 00` |
| 开启保护 | `23 50 26 00 **00** 00 00 00` |
| 关闭保护 | `23 50 26 00 **01** 00 00 00` |

**掉电不保存**（单变量对照实测：唯一被写过的台回退，未碰的三台不变）。
`0x2539` 保存码对它无效——官方 §4.11 明确码 `1` 只保存 PI 参数和最大电流。
`0x2541`（方向）同形、同样不保存。

### 2. 读子索引纠错（已修、已烧板验证）

固件原按 `0x2650:01` 读 → 真机一律 ABORT `0x06090011` → REFRESH 恒挂死 →
全部 CERB 到不了 `DEV_INIT_OK`、**无法使能**。改为 `:00` 后 `last_error` 41 → 40，
位图正确点名不一致槽位。**模拟器与 host 测试此前照固件假设建模（把对象建在 `:01`），
结构上不可能发现此错**——这是本仓库最重要的一条教训。

### 3. 内存账（实测，用于方案决策）

```
DTCM 128 KiB = 主栈 8 KiB + 堆 120 KiB（Heap_useNewlib_ST：malloc 与 pvPortMalloc 同池）
堆的最大占用是 rclc 参数槽：实测 328 B/槽（176/208/224/256 四点一致）
  MAX_PARAMS 224 → heap_free 29,748 B
  MAX_PARAMS 256 → heap_free 19,252 B
micro_ros 任务栈 32 KiB 已改静态分配落 RAM_D1 .bss（腾出 17.4 KB）
```

**48 台 × 15 项 = 730 槽 × 328 B = 240 KB > 120 KB 池 → 参数树这条路不可行。**

### 4. 现有上行带宽（实测）

CDC 上行 4 台时 ~6 KB/s；48 台估算 ~123 KB/s，USB FS 实际吞吐 700–1000 KB/s
→ **5–8 倍余量，带宽不是约束**。真正瓶颈是 `micro_ros` 100Hz 发布循环的 CPU 与堆碎片。

## 二、已达成的设计决定（尚未实现）

| 项 | 决定 |
|---|---|
| 电机配置下发 | **走话题**（不用服务，避开 `MAX_SERVICES` 需联网重建 libmicroros）|
| 参数面 | **保留 `system.*` 10 项**（诊断入口：`last_error`/`heap_free`/`refresh`/`save`）；电机参数撤出 |
| 配置块 | **块 1** = 限位×2/限速/限流/方向/保护（6 项）；**块 2** = PID 六项（`0x2532`–`0x2537`）|
| 块形态 | 命名结构体消息（**不是**字节串+CRC）——字段固定、可逐字段范围校验、类型精确 |
| 字段类型 | `uint32`/`int32`（匹配字典），**不用 float**（PID 是 0..32768 寄存器原值）|
| 保护开关 | 块里**只接受 0（开启）**，写 1 = 整块拒绝；**W25 恒存 0**；不参与上电比对；使能时检查必须为 0 |
| 保护/方向状态 | 进 `motor_status_array` 话题（只读），**不占参数槽** |
| 上电自动写 | 固件启动后主动：保护写 0；方向写 W25 记录值（**无记录 = 未初始化**，判 `CONFIG_CONFLICT`）|
| 方向语义 | 驱动器自己处理限位镜像，固件记录的 cnt 限位值**不用改** |
| `MAX_PARAMS` | 256 → **32**（撤电机参数后）|

## 五、遗留问题（与本次重构无关，独立）

1. **`outstanding` 残留缺陷**：`param_bridge` 的在飞标记只在收到 `CONFIG_RESULT`
   时清除；事务在飞时掉电会**永久残留**，该字段影子同步被无限跳过、参数面卡在旧值。
   复现：写 `m1.limit_protect=1` → 断驱动器电 → 参数面读数不再更新。
   缓解：对同名字段再写一次同值。**未修**。
2. **`0x2541` 方向仍在参数面之外**（按新方案会进块，届时解决）。
3. **48 台规模的 `heap_free` 稳态最低位未测**（本板只有 4 台）。
4. **开保护的自锁风险**：台架停发全部帧静置 5 秒**没有自锁**（单机空载静态）。
