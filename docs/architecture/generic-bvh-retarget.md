# 通用 BVH 离线转换

输入为 BVH 和 URDF。解析格式并不能唯一推断机器人关节的人体语义，因此首次识别给出候选和疑点；用户确认后保存映射，同一组合再次导入自动转换。所有结果保持 `preview_only`，不连接电机或修改模型参数。

## 范围

- 复用 BVH 解析、Pinocchio、SciPy 和现有动作任务、进度、下载、Three.js 预览。
- 树形 URDF 的 fixed、revolute、continuous、prismatic；mimic 按比例/偏移从属，检测循环、缺失引用和不相容限位。
- 浮动/平面多自由度关节及闭环不猜测为独立单轴；报告具体不支持项。
- 名称与人体语义产生候选，重复/无语义名称标为待确认；拓扑决定目标能影响哪些关节。未覆盖分支保持参考位。
- 支持任意数量的目标对应，不限定双臂；人体根参考、机器人坐标、参考帧可确认。
- 第一参考帧对应机器人参考位，拟合相对旋转；移动关节拟合相对平移。固定基座不输出人体根位移，不承诺足底接触、平衡或自碰撞安全。
- 注册仿真模型额外按已映射的上下臂、大小腿骨段方向拟合，避免人体 T 姿被绑定到机器人垂臂零位；先将相对朝向目标的骨轴摆向校准到人体方向，再联合拟合朝向和骨段方向。肩胯安装偏移不当作同构骨段。第一帧为满足位置/耦合范围的初始条件，速度限制从相邻帧开始。报告单独列出骨段方向误差，旧仿真映射缓存需重新确认。
- 两侧肩部及其共同躯干祖先均已映射时，额外用人体根参考到双肩中点的方向校准躯干。机器人方向取腰部末端到肩部首轴安装点中点，避免肩关节旋转改变标尺。该校准同时传给上肢朝向参考，消除 CAD 腰部零位的固有倾斜；仍受原仿真位置、速度及耦合范围约束，报告包含躯干方向误差。
- 同一人体部位不能重复约束一条串联链的多个中间连杆；只给该部位末端连杆设姿态目标，中间关节仍参与求解。自动候选会去除同源串联目标，旧的不合法记录回到确认流程。
- 关节动作保持固定基座定义；预览为机器人补回被根参考归一化掉的每帧朝向，使其与世界坐标中的人体骨架一致。该显示变换不作为实机基座运动导出。
- `root_quaternions` 在机器人坐标基底中表达（`root_rotation_frame: robot`）；旧缓存的未标记字段也使用该约定。若源到机器人的矩阵是 B，显示变换为 Bᵀ·R_root_robot，等价于 R_root_source·Bᵀ；骨架和实体必须共用该变换，不能再次求逆。
- 双足预览每帧根据两足实体网格的最低点估计基座Z，使支撑足落地；人体双足最低点高于估计地面时，按参考根到足底的高度比例保留腾空。地面用源足部轨迹的5%分位高度估计，手部不作为支撑点；无双足结构时保持原参考高度。该处理只影响显示，兼容已有缓存，不写入固定基座关节动作；没有真实接触信息、坡面识别或平衡动力学保证。

## 实现

`bvh_broadcaster.generic_retarget` 集中模型适配、候选分析、映射校验和求解。用实际运动学雅可比拟合目标，保留上一帧初值及连续性项。URDF 原始数值不改写。

正常模式约束有效位置和速度限位。CAD 零范围/缺速度会列出诊断，用户可明确选择“仅几何预览”；此模式只跳过缺失的约束，并在导出及预览中持续标记。它不建立可执行的硬件轨迹。

`MotionJobs` 增加 `retargeting: generic` 输入，旧客户端双臂/肩转换保留。通用任务使用现有状态 `mapping/running/done/failed`，附带候选、诊断、覆盖范围及映射来源。先验证映射再启动计算；不在持有任务锁期间执行完整转换。

确认后的映射保存到用户数据目录；键包含版本、完整 URDF 摘要、BVH 层级/通道/偏移、参考姿势、坐标和单位。每次读取重新验证，失效/损坏回到确认；原子替换单个记录，测试使用临时目录，不读取或覆盖正式缓存。

完整转换结果保存在用户数据目录 `robot2/motion_results`，与映射记录分别保存。缓存键覆盖完整 BVH、有效 URDF、实际映射、坐标/单位、仿真限位、MJCF、显示 URDF、转换相关模块及运行库版本。只发布完整目录；读取校验四个产物的 SHA-256，并再次检查轨迹位置、速度及耦合约束。缓存损坏视为未命中，保存失败只报告不能复用，不丢弃已完成结果。最近三个页面任务仍是临时的；重启后重新导入相同内容即可命中保存结果，选择重新确认映射仍会先停在确认页。

网页复用当前导入、进度与结果视图，增加通用对应表、疑点与限位策略；可选择不对某个连杆设置目标。映射可重新编辑，导出报告说明覆盖与误差。几何预览允许显示超出原 CAD 零限位的姿态，但不改变原 URDF，也不影响控制页的限位。

## DreamsCapStudio 身体广播导入

启动工作台并加载同一个 ROS 工作区后，运行下面的命令，再在 DreamsCapStudio 播放动作。接收端使用厂商 Linux Python Demo 的 T 姿和节点表，默认从 `192.168.1.9:7000/UDP` 采集，提交到 `http://127.0.0.1:8080`，目标模型为 `full_body_robot`。SDK 在其他目录时，用 `--sdk-dir` 指向含 `main.py` 和动态库的 Demo 目录。

```bash
ros2 run web_host record_vdmocap 挥手.bvh --seconds 5
```

成功后在「动作工作台」的「动作库 BVH」选择该文件和对应模型，坐标选自动，单位选厘米，点击「加载并播放」即可预览已保存的解算结果。SDK 录制使用米，导入器生成的 BVH 使用厘米。播放暂停、回到开头或发生长时间丢帧时，录制器提交已经收到的连续片段。提交失败会打印录制 JSON 的临时文件路径，可用 `--input 路径` 重试。

第三方采集程序可直接调用 `POST /api/motion/imports/vdmocap`，请求类型为 `application/json`。请求字段如下。

| 字段 | 格式 |
| --- | --- |
| `name`、`model` | 单层 `.bvh` 文件名和可选的工作台模型名 |
| `capture.world_space` | `WS_Geo`，Z 轴向上 |
| `capture.joints` | SDK 的 23 个身体关节名，与同一请求中所有数组顺序一致 |
| `capture.rest` | 该次 SDK 连接所设的 T 姿世界坐标，23 × 3，单位米 |
| `capture.frames[]` | 每帧含 `index`（uint32）、`frequency`（固定 Hz）、`positions`（23 × 3 世界位置，米）、`quaternions`（23 × 4 世界姿态，wxyz） |

接口按名称恢复骨架，用父关节世界旋转检查每段骨骼的位置，再转换为局部旋转。帧号允许 uint32 回绕，最多补 0.25 秒缺失帧，根位移用线性插值，关节旋转用球面线性插值。每段至少两个原始帧，补齐后最多 7200 帧，请求上限 24 MiB。

目标模型须有适用的部位预设、内置模板或已确认映射。服务完成离线解算并保存结果后才把 BVH 发布到动作库。成功返回 HTTP 200，含 `name`、`model`、`job_id`、`received_frames`、`frames`、`interpolated_frames`、`frequency`、`matched_targets`、`joint_count` 和 `preview_only`。可用 `GET /api/motion/jobs/<job_id>/trajectory` 读取完整关节序列。同名同内容可重试。格式、骨架或模型无法匹配返回 400。同名不同录制、已有转换运行、已有映射需要重新确认或解算期间其内容发生变化时，返回 409 并说明原因。

## DreamsCapStudio 实时跟随

在「动作工作台」选择目标模型，点击「实时跟随」，然后在 DreamsCapStudio 播放。三维视图同时显示源人体骨架和在线解算的机器人。帧号来自广播，Hz 表示源采样率。暂停时保留最后姿态，广播恢复后自动继续。点击「停止实时跟随」或离开动作页会释放接收端。

工作台服务使用 ROS 参数 `vdmocap_sdk_dir`、`vdmocap_ip` 和 `vdmocap_port` 指定 SDK Demo 目录及广播地址，默认值与录制命令相同。服务按 SDK 的身体 T 姿校准，校验每帧的 23 个关节。解算使用最近一次有效姿态作为初值，处理最新广播帧。注册的仿真模型沿用其位置、速度与耦合约束。实时跟随用于三维预览。使用上面的录制命令可将片段保存到动作库。

第三方客户端可向 `POST /api/motion/live/vdmocap` 发送 JSON，例如 `{"model":"full_body_robot"}`，按行读取 `application/x-ndjson` 响应。每行的 `type` 为 `state`、`scene`、`frame` 或 `error`。场景给出骨架和关节顺序，姿态帧包含源帧号、采样率、人体和机器人连杆位置、显示关节位置以及机器人根朝向（xyzw）。服务一次供一个客户端接收，其他客户端连接时返回 HTTP 409。浏览器通过可选的 `viewer` 字段标识同一页面的重连，取值为 32 个小写十六进制字符。

## 验收

1. 新的不同名称/数量/结构的 URDF 可分析、人工确认并转换，不依赖项目模型名。
2. 连续关节跨角度边界、移动关节和 mimic 正负比例得到正确有限结果；畸形映射拒绝。
3. CAD 零限位要求明确选择几何预览，原 URDF 哈希不变；输出持续标记预览及未约束项。
4. 同一骨架/模型/参考姿势确认一次后复用；模型、骨架或参考姿势改变后重新确认。
5. 保留已有双臂/肩转换回归；实际全身短片、预览资源与浏览器确认流程通过。
6. 独立审查接口、映射缓存、限位和数值约束；部署只更新转换/网页安装件，不重启控制栈或操作电机。
