    #等待 ms电机目标（ID:pos,vel,eff）
    说明F1
    • 限位保护上电默认开（固件在回读比对之前写回设备）；取消勾选 = 关闭设备侧看门狗与限位保护，该关节将没有任何限位在执行（急停与机械限位仍需就位），此后该台每次武装都要二次确认，且下次上电会自动恢复为开。限值与保护开关仅在电机未运动时受理。
    • 方向点击切换 CW / CCW。设备方向掉电不保存，固件每次上电按记录写回。翻转只改驱动器的力矩方向，零点与限位都不变（真机实测），但位置环会反向：使能后会朝远离目标的方向冲直到撞上设备限位，所以别在装反的情况下使能。
    • 限值单位：位置 rad、速度 rad/s、力矩 A——前两项与固件状态/URDF 同一套单位，页面上不再出现度数；力矩列是设备对象 0x2538 的电流值（设备里存的就是电流，不折 N·m）。设零要求失能。
    • 使能 / kp / kd 只能写、不能读回（固件无回读通路），框里是页面最后一次下发的值。落地结论看事件日志的 CONFIG_RESULT：0=OK、2=非法。设备参数未核对的台（CONFIG_CONFLICT）会被直接拒。代数必须严格前进才受理「未武装→武装」。
    • 命令快照是完整快照：缺席的受控电机被软停；停止连发 30 ms 后全软停、100 ms 失能；任一 NaN/Inf 整包拒收。
    • 示教：每行等待 ms 后下发该行快照，目标写成 ID:pos,vel,eff；0 目标 = 该行不含此电机。导入接受两种 JSON：本页导出的行数组，或 MotorTrajectory 话题载荷（按时刻合成行）。播放把整表打成一条轨迹交给 MCU，上限 256 个路点（是总点数：4 台时只够 64 行），超限会被固件静默丢弃，页面因此在下发前自查并拒绝。
    • 臂视图与曲线都受 motion_states 的 50 Hz 限制。虚线幽灵 = 页面下发的目标，不是固件设定点；固件的钳位/软停/拒收画不出来。
    • 话题：上行 micro_ros_up/{motor_topology, motion_states, motor_status_array, motor_events, diagnostics, trajectory_state, imu/data, imu/temp}；下行 micro_ros_do/{motor_command_array, motor_trajectory, motor_policy}。
