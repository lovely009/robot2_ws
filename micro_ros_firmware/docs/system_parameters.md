# 固件固定配置与只读查询

运行期系统参数设置、电机参数写入、设零和 SAVE 已移除。固件不再创建 ROS 参数服务，
也不启动 W25 存储任务。仅上电只读加载已有电机记录，保留方向和限位等初始化基准；
不会写入、擦除或覆盖旧记录，旧 SYS1/SYS2 频率配置不再加载。

频率由 `lib/firmware_config/include/firmware_config.h` 编译期定义：Agent 探测 100 Hz、
电机控制 200 Hz、电机运动和状态上报 50 Hz、IMU 100 Hz、温度 2 Hz。CAN 保持
1 Mbps 仲裁段与 5 Mbps 数据段。网页从控制板状态中读取频率，不提供设置或保存。

保留电机发现、身份识别、上电必要归一化（MIT 量程、保护等）、只读参数回读与分页
查询、故障清除，以及受监督的运动/使能策略。运行期不能修改位置/速度/电流限位、
方向、节点 ID、T_max 或零点。旧协议中的写入操作码保留编号，但在 MCU 和主机端拒绝。

修改编译期配置需要重新构建和烧录；本次仅编译验证，没有烧录或擦除设备。
