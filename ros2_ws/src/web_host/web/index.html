限值（位置 度 / 速度 度·秒⁻¹ / 力矩 安培，换算由固件在参数边界做） 与限位保护仅在电机未运动时受理；设零要求失能。取消「限位保护」= 关闭设备侧看门狗与限位保护，该关节将没有任何限位在执行（急停与机械 限位仍需就位），且该设置掉电不保存。

使能 / kp / kd 只能写、不能读回——固件没有回读通路，所以框里显示的是 页面最后一次下发出去的值，不是固件当前值。落地结果看事件日志的 CONFIG_RESULT（reason 0=OK、2=非法；设备参数未核对的台会被 直接拒，这正是 CONFIG_CONFLICT 的含义）。代数必须严格前进才 受理「未武装 → 武装」，防止周期重发在故障后自动复权。
