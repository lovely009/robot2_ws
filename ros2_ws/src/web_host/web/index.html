    设备参数核对：连接后点「读取」

    设零：把该台当前姿态设为设备零点（写 0x2531=1）。厂家要求 失能状态下设置——运行中会被固件拒绝，不会隐式失能；零点改变后设备内的 位置限位随之移动，请重新确认限位与机械行程。
    清错：清除该台的故障锁存（`system.clear_fault`）。仅非运动态受理； 跨总线/协议身份冲突的锁存刻意不可解除（会被拒绝）；设备参数未初始化会触发一次 回读重比对。清完仍须显式使能并重发完整快照/轨迹才可能回运动。 单位：位置 度、速度 度/秒、力矩 安培（设备里的对象就是 cnt / RPM / mA，rad 与 N·m 只在固件内核里用；换算由固件在参数边界做一次）。 参数在固件内核生效：kp/kd/enable 本地立即生效；pos/vel/torque 限值 VAXOR 为 MCU 本地软钳制，CERB 走 CANopen SDO 写后读回核验（要求电机未运动， 运行中写入会被拒绝并回弹）。set 仅表示「已受理」，最终成败看事件日志的 CONFIG_RESULT（失败自动回弹旧值）。「回读」对 CERB 逐条发 SDO upload （设备是严格一问一答，4 个对象读完约 1 秒）刷新设备真实值。「保存到 W25」显式落盘； 设备侧限值/限位写成功即自动落盘，总线上能看到 23 39 25 00 保存帧。 本页只有静态量：enable/kp/kd 是动态量，走下方「逐电机策略」那条话题，不在参数树里。 错误码：11=提交失败（mailbox 被拒）、20=保存失败、 30=回读失败、40=设备与固件记录不一致（该台未初始化）、 41=回读不成功；1..6 为事务结果码（1=BUSY 2=INVALID 3=UNSUPPORTED 4=DEVICE_ERROR 5=TIMEOUT 6=UNCONFIRMED）。 参数以驱动板内为准：「来源」列标出这行数字取自驱动板（在线）还是固件记录 （离线回落）；上电时固件会逐台回读并与 Flash 记录比对，初始化未完成（未回读完 / 与记录不一致 / 回读失败）的那台不可使能（状态列显示 CONFIG_CONFLICT）， 从本页写回参数即可恢复一致。运行中回读发现不一致会走软停（阻尼停机），不硬失能。

    逐电机策略 /motor_policy

    enable 与 MIT 增益走这条话题（不在参数树里）。稀疏语义：只影响下发的那些电机， 其余保持原状——与命令快照的「缺席即软停」不同。代数必须严格前进才受理「从未武装到武装」， 挡的是「周期重发同一条策略」在故障后把电机自动重新武装（固件会拒绝并回 CONFIG_RESULT 事件）。 故障清除后仍须重新武装 + 新的完整快照/轨迹才可能回运动。
