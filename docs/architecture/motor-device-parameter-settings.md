# 电机驱动板方向设置与保存

本次设备页只开放所选 CERB 电机的方向设置和驱动板参数保存；其余参数继续只读。调试页保留观察窗、拖拽条及移动端观察入口。

方向按设备原值 `0=CW / 1=CCW` 写入 `0x2541:00`，复用写后回读核验。此值改变驱动力矩方向，不改变位置坐标。该对象易失且没有厂家保存码，页面明确说明驱动板保存不使方向掉电保持。

保存作用于所选电机驱动板，复用已有 `0x2539` 保存码，范围为位置上下限、速度/电流上限；不写 MCU W25，不开放 ID、保护开关或其他参数修改。保存指令无厂家读回确认，成功文案仅表示设备事务完成发送，不宣称已通过掉电验证。VAXOR 不提供这两项入口能力。

保留既有消息布局：`ConfigRequest` 参数写仅接受一个方向目标；新增 `SystemCommand.COMMAND_SAVE_DEVICE=5` 映射现有 Agent `SAVE=5`，仅接受有效单电机 ID。旧全局 SAVE 与固件配置仍拒绝。前后端及 MCU 均检查目标、值、会话和时效；执行前必须已失能、空闲且无轨迹占用。事务保留幂等、同号异内容冲突、终态回执和超时未知语义；待完成的参数事务阻止重新使能。

驱动板保存不表示 MCU 参数记录已落盘，不能清除 `record_dirty_slots`。方向写入仍更新内存记录并保留脏位。

验证采用虚拟设备及假 rosbridge：CW/CCW 精确编码、失能/离线/处理中门禁、单电机保存、无自动保存、取消不发送、失败及断连不显示成功、非法参数整条拒绝、同号不同方向冲突、设备事务路由和调试页布局。构建前后端与固件并独立审查；不在当前连接设备上执行方向修改或 Flash 保存。需要更新板上固件时单独取得部署授权。
