# W25Q64 OCTOSPI2 Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将官方 W25Q64 OCTOSPI2 Quad 驱动移入固件 `lib/`，以非破坏性启动探测完成集成并通过开关双构建。

**Architecture:** `lib/w25q64` 同时拥有 OCTOSPI2 HAL 初始化、W25Q64 命令驱动和无 HAL 的参数校验。启动任务仅调用统一初始化并记录诊断；擦除、写入和 memory-mapped 接口只作为库能力提供，不在上电流程执行。

**Tech Stack:** C17、STM32H7 HAL OSPI/OSPIM/GPIO/RCC、PlatformIO、STM32duino、CMake/CTest。

**Spec:** `docs/superpowers/specs/2026-08-31-w25q64-ospi-driver-design.md`

## Global Constraints

- 使用 OCTOSPI2 Port 1 Quad 固定引脚：PB2 CLK、PE11 NCS、PD11 IO0、PB0 IO1、PA3 IO2、PA1 IO3。
- BMI088 保持 PC0 ACC_CS、PC3 GYRO_CS，不修改 IMU 引脚或 SPI2 数据流。
- Flash 容量固定 8 MiB、page 256 B、sector 4 KiB；所有地址和长度在 HAL 调用前有界校验。
- 上电只初始化、reset、等待 ready 和读取 JEDEC ID，不擦除、不写入、不进入 memory-mapped。
- Flash 初始化失败不得阻止 control、sensor、micro-ROS 或 supervisor 任务启动。
- 运行期 Flash 并发和参数记录格式不在本计划范围内。

- [ ] **Step 1: 写入失败的 geometry 测试**

```cpp
#include "w25q64_geometry.h"

#include <cassert>

int main() {
  assert(w25q64_range_valid(0U, 0U));
  assert(w25q64_range_valid(W25Q64_FLASH_SIZE - 1U, 1U));
  assert(!w25q64_range_valid(W25Q64_FLASH_SIZE, 1U));
  assert(!w25q64_range_valid(W25Q64_FLASH_SIZE - 1U, 2U));

  assert(w25q64_page_program_valid(0U, W25Q64_PAGE_SIZE));
  assert(w25q64_page_program_valid(255U, 1U));
  assert(!w25q64_page_program_valid(255U, 2U));
  assert(!w25q64_page_program_valid(0U, W25Q64_PAGE_SIZE + 1U));

  assert(w25q64_erase_address_valid(0U, W25Q64_SECTOR_SIZE));
  assert(w25q64_erase_address_valid(W25Q64_SECTOR_SIZE,
                                     W25Q64_SECTOR_SIZE));
  assert(!w25q64_erase_address_valid(1U, W25Q64_SECTOR_SIZE));
  assert(!w25q64_erase_address_valid(W25Q64_FLASH_SIZE,
                                      W25Q64_SECTOR_SIZE));
  assert(w25q64_erase_address_valid(0U, 32768U));
  assert(w25q64_erase_address_valid(0U, 65536U));
  assert(!w25q64_erase_address_valid(0U, 8192U));
  return 0;
}
```

`../../lib/w25q64/src/w25q64_geometry.c` 并包含 `../../lib/w25q64/include`。

- [ ] **Step 3: 实现最小 geometry 校验**

`w25q64_range_valid` 使用 `address <= FLASH_SIZE` 且
`size <= FLASH_SIZE - address`，避免 `address + size` 溢出。
`w25q64_page_program_valid` 先要求 `size` 为 1..256 且 range 合法，再比较起止
地址的页号。`w25q64_erase_address_valid` 只接受 4096/32768/65536，要求地址按
粒度对齐且完整块位于 Flash 内。

- [ ] **Step 1: 建立 PlatformIO 库清单和公共状态类型**

`library.json`：

```json
{
  "name": "w25q64",
  "version": "0.1.0",
  "build": { "includeDir": "include", "srcDir": "src" }
}
```

在 `w25q64.h` 定义：

```c
typedef enum {
  W25Q64_OK = 0,
  W25Q64_ERROR_ARGUMENT = -1,
  W25Q64_ERROR_HAL = -2,
  W25Q64_ERROR_TIMEOUT = -3,
  W25Q64_ERROR_ID = -4,
  W25Q64_ERROR_STATE = -5,
} w25q64_status_t;
```

- [ ] **Step 2: 移植 OCTOSPI2 初始化**

从参考 `Core/Src/octospi.c` 提取 OCTOSPI2/OSPIM/GPIO/RCC 初始化到
`octospi.c`。使用静态 `OSPI_HandleTypeDef g_hospi2`，通过
`OSPI_HandleTypeDef *octospi2_handle(void)` 暴露给驱动；所有 HAL 失败返回
`W25Q64_ERROR_HAL`，不调用 `Error_Handler()`。增加静态 initialized guard；deinit
关闭 OSPI2/OSPIM 并恢复六个 GPIO。

- [ ] **Step 3: 移植并收紧 W25Q64 命令**

从参考 `Devices/W25Q64/w25q64.c` 移植 reset、JEDEC ID、status polling、write
enable、erase、Quad page program、Quad IO read、跨页 write 和 memory-mapped。
每个 public API 首先调用 Task 1 geometry 校验；`data == NULL && size != 0` 返回
`W25Q64_ERROR_ARGUMENT`。HAL 默认命令超时使用 1000 ms；sector/block/chip busy
轮询分别使用 1000/3000/100000 ms 有界超时。

`w25q64_init()` 顺序固定为：

```c
octospi2_init();
w25q64_reset();
w25q64_wait_ready(1000U);
return w25q64_read_id() == W25Q64_JEDEC_ID ? W25Q64_OK : W25Q64_ERROR_ID;
```
