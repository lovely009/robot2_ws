## 已证实的问题

主 URDF 的 19 个连杆总质量为 8.536224630 kg。CAD CSV 的 SW Components 列将整台电机列在如下连杆中，但该连杆的导出总质量甚至低于电机自身规格重量。主 URDF 继承了这些 CAD 数值（部分保留 5 位有效数字），不是本次 STL 替换造成的差异。左右同类连杆都受影响。

| 连杆 | 当前总质量 / g | CAD 组件中列出的电机 |
|---|---:|---|
| `Joint_link2` | 152.070 | 1×R58（460 g/台） |
| `Joint_link3` | 144.170 | 1×R58（460 g/台） |
| `Joint_link4` | 153.511 | 1×R48（260 g/台） |
| `Joint_link6` | 84.684 | 1×R48（260 g/台） |
| `Joint_link2.2` | 152.067 | 1×R58（460 g/台） |
| `Joint_link3.3` | 144.166 | 1×R58（460 g/台） |
| `Joint_link4.4` | 153.511 | 1×R48（260 g/台） |
| `Joint_link6.6` | 84.684 | 1×R48（260 g/台） |

电机重量依据仓库 `docs/巨蟹电机/CE-RB-R48-101-Lite-CO-I-参数规格.pdf` 和 `CE-RB-R58-101-Lite-CO-I-参数规格.pdf` 第 1 页参数表：R48 260 g，R58 460 g。这是厂商规格，未实物称重。CAD 各组件原来的质量贡献未知，不能直接向现有连杆叠加整台电机质量，否则可能重复计重；也不能仅按总质量比例缩放惯量，因为质量分布会改变。

另有来源差异：`Joint_link2.2` 当前质心为 `(0.005348356, 0.018045086, -0.028822506)` m，原 CAD 导出为 `(0.004282894, 0.018045086, -0.033299975)` m；部分惯性分量也不同，超出五位有效数字舍入范围。该修改的依据尚未核实，本轮保留现状，不假定原 CAD 参数正确并回退。

## 新 STL 检查

STL 不保存材料、密度、质量属性或长度单位。根据电机规格尺寸与现有米制网格匹配，本批输入按毫米解释，接入 URDF 必须转换为米或明确设置 scale。原文件未改写。

| 文件 | 三角面 | 边界边 | 非流形边 | 闭合有向体积 / cm³ |
|---|---:|---:|---:|---:|
| `CE-RB-R48-101-Lite-CO-I(2).STL` | 112515 | 137 | 118 | 不可直接积分 |
| `CE-RB-R58-101-Lite-CO-I.STL` | 23635 | 6597 | 0 | 不可直接积分 |
| `xiaobigujia.STL` | 6042 | 0 | 0 | 52.939 |
| `zhoubuguanjiexuanzhuanzhou(wuerban).STL` | 3104 | 0 | 0 | 27.440 |
| `装配体4.STL` | 9514 | 0 | 0 | 131.547 |
| `装配体5.STL` | 4132 | 0 | 0 | 92.960 |
| `装配体6.STL` | 3870 | 0 | 0 | 53.101 |

拓扑统计按 STL 原始 float32 顶点的精确坐标合并后计算。闭合只表示每条无向边有两个相邻面，不证明没有自交、重叠实体或材料混合。5 个结构件/子装配可在确认材料与装配关系后计算质量属性。两个电机网格不满足直接体积积分条件；不把补洞或凸包当成真实内部材料分布。

新 R58 网格经旋转平移后能匹配现有 `Joint_link3` 内的电机几何：对 1400 个确定性顶点样本，最近旧网格顶点距离的 80 分位约 0.0000023 mm。该证据支持组件身份和毫米单位，不证明整个连杆几何正确，也不能确定电机内部惯量。其余结构件的刚体变换和连杆归属尚未验收，不能按最近配准结果自动替换。

## 修复需要的最小输入

优先从正确赋材质且完成电机质量覆盖的 SolidWorks 装配，按 URDF 每个连杆的组件分组导出：质量（kg）、质心（m）、关于质心且表达在连杆坐标系中的惯性张量（kg·m²），并提供对应坐标系。CAD 若输出惯性积而非张量非对角元，需明确符号约定。

若只能使用 STL，需要确认 5 个结构件/子装配的材料或实测质量、装配体4/5/6包含的组件及对应连杆、组件到连杆的刚体变换，并补充电机和腕部组件的质量分布依据。均匀密度法只能作为注明假设的估计，不称为实测或标定结果。

拿到依据后更新主 URDF，再同步 standalone、MuJoCo 和 cad/frames 派生件；验收质量汇总、坐标/单位、平行轴合成、主惯量和派生一致性。未进行真机动作、重力补偿验收或烧录。
